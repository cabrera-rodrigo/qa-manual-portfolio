# Portfolio QA Manual - Pruebas Funcionales E-Commerce

Repositorio con la documentación, diseño de casos de prueba y reporte de incidencias realizadas sobre la plataforma de práctica **Automation Exercise**.

El trabajo simula el ciclo de vida de pruebas (STLC) completo desde el relevamiento inicial de módulos críticos hasta la ejecución manual y el seguimiento de defectos.

## Estructura del Proyecto

* **[01 - Plan de Pruebas](./docs/01_Plan_de_Pruebas.md):** Definición de alcance, estrategia, entorno y criterios de aceptación.
* **[02 - Casos de Prueba](./docs/02_Casos_de_Prueba.md):** Matriz con escenarios positivos (Happy Path) y negativos diseñados para cada flujo.
* **[03 - Reporte de Bugs](./docs/03_Reporte_de_Bugs.md):** Documentación detallada de defectos detectados con severidad, pasos de reproducción y capturas de evidencia.
